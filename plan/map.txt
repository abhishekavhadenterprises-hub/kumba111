Step 1: Read KML File

KML is XML-based:

<Placemark>
  <name>Mumbai</name>
  <Point>
    <coordinates>
      72.8777,19.0760
    </coordinates>
  </Point>
</Placemark>

Convert KML → GeoJSON using:

Libraries
npm install @tmcw/togeojson
npm install xmldom

Example:

import { DOMParser } from "xmldom";
import { kml } from "@tmcw/togeojson";

const xml = new DOMParser().parseFromString(
  kmlContent,
  "text/xml"
);

const geojson = kml(xml);

on map using Polyline.

Step 3: Animate Celebrity Movement

Create a marker:

new mapboxgl.Marker()

Move marker along coordinates:

requestAnimationFrame()

Animation:

● Mumbai

  \

     \
      \
       ● Nashik

Like Uber tracking.
